# SmartCare 
## 项目简介
本项目是一个基于 `SpringBoot` + `Vue3` 的前后端分离智慧养老平台，
用于对养老设备采集的生理数据进行实时存储、分析与可视化展示。

系统支持设备数据接入、健康指标统计、异常预警及数据管理等功能，
可应用于养老机构或家庭远程健康监测场景

### 技术栈
| 层级   | 技术              |
| ---- | --------------- |
| 后端   | SpringBoot      |
| ORM  | MyBatis-Plus    |
| 定时任务 | Spring Schedule |
| 数据库  | MySQL           |
| 前端   | Vue3            |
| 部署   | Nginx           |

### 技术亮点
设备端每 5 秒向服务端上传一次生理数据（心率、呼吸率等），在高并发及长期运行场景下，原始数据表会快速膨胀，导致：
* 查询性能下降
* 索引效率降低
* 分页扫描成本升高
  
优化方案：
* 使用 Spring Schedule 定时任务
* 对历史原始数据进行周期性统计汇总
* 对超过阈值时间的数据进行归档和分表

## 后续优化方向
- 异步消息队列处理（如 RabbitMQ）
  - 场景：检测到心率异常后，需要触发「邮件通知 / 异常审理 / 事件记录」等一系列后续流程。
  - 问题：若在主链路内同步执行（包含多服务/多表查询与第三方邮件发送），会显著拉长接口耗时，并在高峰期放大失败率与数据库压力。
  - 方案：引入 RabbitMQ 将异常事件异步化处理，实现业务解耦与削峰。
    - 生产端开启持久化与发布确认（Publisher Confirm），确保消息可靠投递到 Broker
    - 消费端采用手动 ACK，失败自动重试；多次失败进入死信队列（DLQ）便于人工审理/补偿
    - 消费逻辑保证幂等（基于 event_id 去重），避免重复通知
  - 效果：异常告警从「同步阻塞」改为「可靠异步」，提升接口响应与系统稳定性，并具备可追溯的事件记录链路。
